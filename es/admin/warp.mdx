El comando `/master warp` te teletransporta a ti, el jugador que lo ejecuta, a un punto de warp nombrado definido en el mapa del evento de Crystal Legacy. Úsalo para navegar rápidamente entre ubicaciones clave como áreas de aparición, arenas o cualquier otro punto que el autor del mapa haya configurado, sin necesidad de conocer las coordenadas exactas.

## Sintaxis

```bash
/master warp ;location;
```

Reemplaza `;location;` con el nombre del punto de warp al que quieres viajar. La lista completa de puntos de warp disponibles está definida por el mapa del evento cargado actualmente en el servidor.

## Ejemplos

Teletransportarte al punto de aparición principal:

```bash
/master warp spawn
```

Teletransportarte a la arena:

```bash
/master warp arena
```
