Crystal Legacy es un mod de eventos basado en estados. El servidor avanza a través de cinco fases globales distintas en secuencia, y cada fase controla exactamente lo que los jugadores ven en sus HUDs, qué mecánicas están activas y qué interacciones están permitidas. Avanzas a través de las fases manualmente usando el comando maestro: nada cambia automáticamente sin la intervención de un operador.

## Orden de las Fases

Avanza a través de los estados en el siguiente orden usando `/master estado <state>`:

```text
DEV → WAITING_PLAYERS → TUTORIAL → MINI_EVENTS → PVP
```

## Referencia de Fases

| State | Propósito |
| --- | --- |
| DEV | Estado de reposo/predeterminado al iniciar el servidor. Ninguna fase de evento activa. |
| WAITING_PLAYERS | Pantalla de sala de espera. Los jugadores esperan hasta que se conecten los 30. |
| TUTORIAL | Secuencia de tutorial automatizada que enseña los 4 hechizos. |
| MINI_EVENTS | Minijuego de parkour con puntos de control y temporizador de 10 minutos. |
| PVP | Torneo de eliminación directa, termina con créditos finales. |

## Cambiar el Estado Activo

Usa el siguiente comando para cambiar entre fases:

```bash
/master estado ;state;
```

Reemplaza `;state;` con uno de los cinco nombres de estado listados arriba (por ejemplo, `WAITING_PLAYERS`, `TUTORIAL`, etc.).

<Note>
  Si un jugador se une en medio de cualquier fase, el servidor detecta automáticamente la conexión tardía y sincroniza la interfaz correcta, los paquetes y el estado para ese jugador. No necesitas intervenir manualmente para las conexiones tardías estándar.
</Note>
