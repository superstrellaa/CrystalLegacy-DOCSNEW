The `/master data clear` command is your primary recovery tool when something goes wrong mid-event or when you need to reset a specific system before re-running a phase. It clears in-memory event data on the server and sends a reset packet to all connected clients, returning their UI and state to defaults. This command does **not** touch any persistent database records — everything it affects lives only in memory for the duration of the current session.

<Note>
  All `/master data clear` subcommands operate on in-memory state only. No persistent database records are modified, created, or deleted by any variant of this command.
</Note>

## Root Command

Running the root command with no subcommand (or with `all`) performs a full reset across every system:

```bash
/master data clear
```

This is equivalent to:

```bash
/master data clear all
```

Use this as a nuclear option when you need to wipe everything and start fresh without rebooting the server.

## Subcommands

| Subcommand | Description |
| --- | --- |
| `all` | Clears all in-memory event data and resets all clients. Identical to running the root command with no argument. |
| `bracket` | Clears only the procedurally generated PVP bracket image. Use this if you need to regenerate the bracket display without affecting other PVP state. |
| `client` | Sends the client-reset packet to all players without clearing any server-side data. Useful for fixing client UI desync. |
| `client dialogo` | Immediately removes any dialogue or dialogue overlay currently displayed on all clients. |
| `client pvp` | Clears all PVP-related data on the client side only. Server-side PVP state is left intact. |
| `client spectators` | Removes the spectator state from players who were eliminated during the PVP final. |
| `parkour` | Clears all dynamic parkour data including checkpoint progress and completion flags. |
| `pvp` | Clears both client-side and server-side PVP state in a single operation. |
| `timer` | Stops the currently running countdown timer and clears its state. |
| `torneo` | Clears PVP tournament bracket state on the server. **Not recommended for normal event use.** |
| `tutorial` | Clears all tutorial state and progress for all players. |
| `voicechat` | Resets voice chat permissions to the default state, allowing all players to speak freely. |

<Warning>
  Avoid using `torneo` during a live event unless you fully understand the consequences. Clearing tournament bracket state mid-event will discard all match results and progression, and there is no way to restore them automatically.
</Warning>

## Examples

```bash
/master data clear parkour
/master data clear timer
/master data clear client dialogo
/master data clear pvp
/master data clear voicechat
```
