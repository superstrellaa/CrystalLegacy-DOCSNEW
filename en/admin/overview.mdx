Every admin action in Crystal Legacy flows through a single root command: `/master`. From transitioning event phases to resetting client state, managing player keys, controlling background music, and triggering the PVP bracket — everything you need to run a 30-player event is reachable from this one namespace. All subcommands require OP; non-OP players will receive a permission error or see no response at all.

<Warning>
  All `/master` commands require server operator (OP) privileges. Attempting to run any subcommand without OP will fail silently or return a permission error. Always confirm your OP status before running commands during a live event.
</Warning>

## Getting Started

Before advancing through event phases, use `/master info` at any time to get a full debug readout of the current event state. This includes the active phase, registered players, timers, voice chat status, and more. Make it your first stop whenever something looks off.

```bash
/master info
```
