Crystal Legacy is a state-driven event mod. The server moves through five distinct global phases in sequence, and each phase controls exactly what players see on their HUDs, which mechanics are active, and what interactions are permitted. You advance through phases manually using the master command — nothing transitions automatically without operator input.

## Phase Order

Advance through states in the following order using `/master estado <state>`:

```text
DEV → WAITING_PLAYERS → TUTORIAL → MINI_EVENTS → PVP
```

## Phase Reference

| State | Purpose |
| --- | --- |
| DEV | Idle/default state on server boot. No event phase active. |
| WAITING_PLAYERS | Lobby screen. Players wait until all 30 are connected. |
| TUTORIAL | Automated tutorial sequence teaching the 4 spells. |
| MINI_EVENTS | Parkour minigame with checkpoints and 10-min timer. |
| PVP | Single-elimination tournament bracket, ends with credits. |

## Changing the Active State

Use the following command to transition between phases:

```bash
/master estado ;state;
```

Replace `;state;` with one of the five state names listed above (e.g. `WAITING_PLAYERS`, `TUTORIAL`, etc.).

<Note>
  If a player joins mid-state during any phase, the server automatically detects the late join and syncs the correct UI, packets, and state to that player. You do not need to manually intervene for standard late joins.
</Note>
