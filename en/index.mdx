Crystal Legacy is a Minecraft 1.21.1 Fabric event mod built for organized 30-player events. It delivers four custom spells, an automated tutorial sequence, a parkour mini-event, and a single-elimination PVP tournament — all driven by a server-side state machine and controlled through the `/master` admin command suite.

## How the Event Works

Crystal Legacy runs through a sequence of global states. The operator advances the event from state to state using `/master estado ;state;`. Each state controls what every connected player sees and can do.

<Steps>
  <Step title="Launch the server">
    Start the Crystal Legacy server. It boots into **DEV** state — a neutral idle state where no event phase is active.
  </Step>
  <Step title="Connect players">
    Switch to **WAITING_PLAYERS**. Players who join see the waiting screen. Voice chat is automatically muted until the event begins.
  </Step>
  <Step title="Run the tutorial">
    Advance to **TUTORIAL**. Each of the 30 players is assigned a dedicated map slot and the automated tutorial sequence teaches them the four spells.
  </Step>
  <Step title="Run mini-events and PVP">
    Continue through **MINI_EVENTS** (parkour) and then **PVP** (single-elimination bracket). The server builds the bracket automatically from all registered players.
  </Step>
</Steps>

<Note>
  Every state transition is handled by the server. If a player joins mid-event, the server automatically detects the active state and syncs the correct packets and UI to that player.
</Note>
