The Crystal Legacy client ships as a self-contained Modrinth modpack (`.mrpack`). It includes every required Fabric mod, all resource packs, and a pre-configured title screen that connects you to your event server with a single button. Setup takes only a few minutes: import the modpack into the Modrinth App, point it at your server's address, and you are ready to play.

<Note>
  The **Modrinth App** is the recommended launcher for Crystal Legacy. It handles Java 21 installation and instance management automatically. Other Fabric-capable launchers (MultiMC, Prism Launcher, ATLauncher) can also import `.mrpack` files, but the Modrinth App provides the smoothest experience.
</Note>

## Requirements

| Resource | Recommended |
| --- | --- |
| Java | 21 |
| RAM | ~8 GB allocated to the instance |

## Setup Steps

<Steps>
  <Step title="Import the modpack into the Modrinth App">
    Open the **Modrinth App**, then add the downloaded `client.mrpack` file as a new instance:

    1. Click **Add Instance** (or the **\+** button in the instances panel).
    2. Choose **Import from file** and select the `client.mrpack` you just downloaded.
    3. Wait for the launcher to finish downloading the mods and resource packs. Once it completes, the instance is fully installed and ready to launch.

    <Tip>
      In the instance settings, allocate at least **8 GB of RAM** for the smoothest experience.
    </Tip>
  </Step>
  <Step title="Point the client at your server">
    The title screen's **Play** button is pre-wired to connect to a server address stored in a FancyMenu layout file. You need to replace the default `localhost:25565` placeholder with your actual server IP and port.

    Open the installed instance folder from the Modrinth App (right-click the instance and choose **Open Folder**), then open the following file in any plain-text editor:

    ```text
    /config/fancymenu/customization/title_screen_layout.txt
    ```

    Search for the line containing `joinserver`. It looks like this:

    ```text title="title_screen_layout.txt — before"
    [executable_action_instance:<uuid>][action_type:joinserver] = localhost:25565
    ```

    Replace the address after the `=` with your server's IP address and port:

    ```text title="title_screen_layout.txt — after"
    [executable_action_instance:<uuid>][action_type:joinserver] = 203.0.113.42:25565
    ```

    <Note>
      The `<uuid>` portion of the key is a unique identifier generated when the layout was built. Leave it exactly as-is. Only change the value to the right of the `=` sign.
    </Note>

    Save the file and close your editor.
  </Step>
  <Step title="Launch the game and join the event">
    Start the instance from the Modrinth App. Once the title screen loads, click the **Play** button and Crystal Legacy will connect you directly to the configured server address.

    If the server is in the `WAITING_PLAYERS` phase, you will be placed in the lobby automatically. If an event is already in progress, the server will sync you to the current phase so you can join without missing a beat.
  </Step>
</Steps>

## Troubleshooting

<Warning>
  If the **Play** button produces a "Connection refused" error, double-check that the IP address and port in `title_screen_layout.txt` are correct and that the server is running. You can also add the server manually via **Multiplayer → Add Server** as a fallback.
</Warning>
