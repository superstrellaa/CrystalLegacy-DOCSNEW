The Crystal Legacy client ships as a self-contained modpack instance. It includes every required Fabric mod, all resource packs, and a pre-configured title screen that connects you to your event server with a single button. Setup takes only a few minutes — extract the archive, point the client at your server's address, and you are ready to play.

<Note>
  The **Modrinth App** is the recommended launcher for Crystal Legacy. It handles Java 21 installation and instance management automatically. That said, any launcher capable of running a Fabric modpack instance — such as MultiMC, Prism Launcher, or ATLauncher — will work perfectly well.
</Note>

## Requirements

| Resource | Recommended |
| --- | --- |
| Java | 21 |
| RAM | ~8 GB allocated to the instance |

## Setup Steps

<Steps>
  <Step title="Download and extract the client archive">
    Download `client.zip` from the link your organizer provided. Extract it to a location of your choice — a dedicated `CrystalLegacy` folder on your desktop works well.

    ```bash title="Extract on Linux / macOS"
    unzip client.zip -d crystal-legacy-client
    cd crystal-legacy-client
    ```

    On Windows, right-click `client.zip` in File Explorer and choose **Extract All…**, then open the resulting folder.
  </Step>
  <Step title="Point the client at your server">
    The title screen's **Play** button is pre-wired to connect to a server address stored in a FancyMenu layout file. You need to replace the default `localhost:25565` placeholder with your actual server IP and port.

    Open the following file in any plain-text editor:

    ```text
    /config/fancymenu/customization/title_screen_layout.txt
    ```

    Search for the line containing `joinserver`. It looks like this:

    ```text title="title_screen_layout.txt — before"
    [executable_action_instance:<uuid>][action_type:joinserver] = localhost:25565
    ```

    Replace the address after the `=` with your server's IP address and port:

    ```text title="title_screen_layout.txt — after"
    [executable_action_instance:<uuid>][action_type:joinserver] = 203.0.113.42:25565
    ```

    <Note>
      The `<uuid>` portion of the key is a unique identifier generated when the layout was built — leave it exactly as-is. Only change the value to the right of the `=` sign.
    </Note>

    Save the file and close your editor.
  </Step>
  <Step title="Import the instance into your launcher">
    **Modrinth App (recommended)**

    1. Open the Modrinth App and click **Add Instance**.
    2. Choose **Import from file** and select the extracted client folder (or the `.mrpack` file if one is included in the archive).
    3. Set the allocated RAM to **8 GB** in the instance settings, then save.

    **Other Fabric-capable launchers (MultiMC, Prism, ATLauncher, etc.)**

    1. Create a new instance and choose **Import** or **From zip/folder**.
    2. Point the launcher at the extracted client folder.
    3. Ensure the instance uses **Fabric** as its mod loader and **Minecraft 1.21.1** as the game version.
    4. Allocate at least **8 GB** of RAM in the instance's Java settings.
  </Step>
  <Step title="Launch the game and join the event">
    Start the instance from your launcher. Once the title screen loads, click the **Play** button — Crystal Legacy will connect you directly to the configured server address.

    If the server is in the `WAITING_PLAYERS` phase, you will be placed in the lobby automatically. If an event is already in progress, the server will sync you to the current phase so you can join without missing a beat.
  </Step>
</Steps>

## Troubleshooting

<Warning>
  If the **Play** button produces a "Connection refused" error, double-check that the IP address and port in `title_screen_layout.txt` are correct and that the server is running. You can also add the server manually via **Multiplayer → Add Server** as a fallback.
</Warning>
