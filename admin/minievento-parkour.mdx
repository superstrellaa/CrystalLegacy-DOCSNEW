The `/master minievento parkour` command group lets you control the parkour mini-event during the `MINI_EVENTS` phase. Use these commands to recover from a bad state, wipe leftover data, or shut down the minigame entirely without affecting the broader event flow.

## Syntax

```bash
/master minievento parkour ;subcommand;
```

## Subcommands

| Subcommand | Description |
|---|---|
| `clear` | Clears all dynamic parkour data. Same as `/master data clear parkour`. |
| `reset` | Resets the parkour minigame to its initial state. |
| `stop` | Stops the parkour minigame entirely. |

## Examples

```bash
/master minievento parkour reset
/master minievento parkour stop
/master minievento parkour clear
```

## Recovering a Stuck Parkour

<Tip>
  `reset` is the most common command — use it if the parkour gets into a bad state and you need to restart it without changing the overall event state. It brings the minigame back to its initial conditions while leaving all other `MINI_EVENTS` phase logic untouched.
</Tip>
