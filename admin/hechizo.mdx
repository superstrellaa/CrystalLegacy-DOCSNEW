Crystal Legacy gives each player access to a set of spells that they unlock progressively throughout the event. The `/master hechizo` and `/master minijuego` commands let you take manual control of that process — blocking or granting spells directly, or launching the unlock minigame for a specific player outside of the normal Tutorial flow.

<Note>
  Spells are normally unlocked automatically during the Tutorial sequence. Use these commands only when you need to manually grant or revoke spell access outside of that flow, such as when troubleshooting or running a custom scenario.
</Note>

## `/master hechizo`

Use `/master hechizo` to block or unblock a specific spell for one or more players. This is a direct grant or revocation — no minigame is involved.

### Syntax

```bash
/master hechizo bloquear ;spell; ;player(s);
/master hechizo desbloquear ;spell; ;player(s);
```

Replace `;spell;` with one of the available spell names and `;player(s);` with a player name or selector.

### Available Spells

| Spell | Description |
|---|---|
| `dash` | Quick directional dash |
| `bola_de_fuego` | Launches a fireball projectile |
| `levioso` | Levitates the target |
| `hachazo` | Delivers a powerful axe strike |

### Examples

Block the `dash` spell for all players:

```bash
/master hechizo bloquear dash @a
```

Unblock `levioso` for a specific player:

```bash
/master hechizo desbloquear levioso Steve
```

---

## `/master minijuego`

Use `/master minijuego` to start the spell-unlock minigame for a given spell and player(s). When the player completes the minigame, that spell is unlocked for them. This mirrors the mechanism used during the Tutorial sequence and is the intended way to introduce players to each spell in a guided manner.

### Syntax

```bash
/master minijuego ;spell; ;player(s);
```

### Examples

Start the `dash` unlock minigame for all players:

```bash
/master minijuego dash @a
```

Start the `hachazo` minigame for a specific player:

```bash
/master minijuego hachazo Steve
```
