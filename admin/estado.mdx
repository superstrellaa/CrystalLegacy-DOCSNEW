The `/master estado` command is the primary lever for advancing Crystal Legacy through its event lifecycle. Each state activates a distinct set of systems — from the lobby screen and voice chat rules all the way through to the PVP tournament bracket. Transitioning to a new state does not automatically undo the previous one, so follow the intended order and use `/master data clear` subcommands if you need to roll back specific systems.

<Note>
  Transitioning states is effectively irreversible during a normal event run. If you need to reset a specific phase — for example, clearing parkour progress or wiping the tutorial state — use the appropriate `/master data clear` subcommand rather than re-entering a previous state blindly.
</Note>

## Syntax

```bash
/master estado ;state;
```

Replace `;state;` with one of the five valid state identifiers listed in the table below.

## Valid States

| State | Description |
|---|---|
| `DEV` | Idle state. Default on server boot. No event phase is active. Use this between test runs or when the server is on standby. |
| `WAITING_PLAYERS` | Lobby screen is shown to all players while they wait for the event to begin. |
| `TUTORIAL` | Activates the automated tutorial sequence for all participants. |
| `MINI_EVENTS` | Starts the mini-events phase, including the parkour minigame with checkpoint tracking. |
| `PVP` | Activates the single-elimination tournament bracket and begins the PVP phase. |

## Intended Order

Run the states in the following sequence for a standard event:

```text
DEV → WAITING_PLAYERS → TUTORIAL → MINI_EVENTS → PVP
```

Start in `DEV` while you prepare the server. Move to `WAITING_PLAYERS` once you are ready to admit participants to the lobby. Advance to `TUTORIAL` when all 30 players have joined, then to `MINI_EVENTS` for the parkour phase, and finally to `PVP` to run the tournament.

## Examples

```bash
/master estado WAITING_PLAYERS
/master estado TUTORIAL
/master estado MINI_EVENTS
/master estado PVP
/master estado DEV
```
